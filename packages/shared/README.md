# @vila/shared

Lógica pura compartilhada por `apps/client`, `apps/api` e `apps/server` (sem DOM, sem three.js, sem runtime da
Cloudflare): mundo e obstáculos, movimento do avatar, missões/XP, ambiente (hora de SP, clima, keyframes) e o
protocolo de presença. Consumida como TypeScript direto (`@vila/shared/<pasta>/<módulo>`), sem etapa de build.
Ver [docs/reference/architecture.md](../../docs/reference/architecture.md).
